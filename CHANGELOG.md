# Changelog

## [1.0.0] - 2026-09-27

### Добавлено

- Диалоговая система для Assist: ответы по мере генерации, управление устройствами, история диалога.
- Задача ИИ: текст, JSON по схеме, вложения, генерация картинок через `text2image`.
- Сенсоры остатка токенов по семействам моделей и счётчик расхода токенов.
- Настройка в интерфейсе: несколько агентов, повторная аутентификация, перенастройка, диагностика.
- Интерфейс на русском и английском.

### Added

- Assist conversation agent: streamed answers, device control, conversation history.
- AI task: text, JSON following a schema, attachments, image generation with `text2image`.
- Token balance sensors per model family and a token usage counter.
- UI configuration: multiple agents, reauthentication, reconfiguration, diagnostics.
- Russian and English UI.
