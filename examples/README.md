# Примеры автоматизаций / Automation examples

Скопируйте YAML в *Настройки → Автоматизации → Создать → ⋮ → Редактировать в YAML* и замените объекты
на свои.

Paste the YAML into *Settings → Automations → Create → ⋮ → Edit in YAML* and replace the entities with
your own.

| Файл / File | Что делает | What it does |
|---|---|---|
| [hourly_fact.yaml](hourly_fact.yaml) | С 9 до 21 колонка каждый час рассказывает проверенный факт | From 9 to 21 a speaker tells a fact-checked fact every hour |
| [coffee_fact.yaml](coffee_fact.yaml) | Факт после выключения кофемашины | A fact when the coffee machine turns off |
| [morning_briefing.yaml](morning_briefing.yaml) | По будням: погода на день и события календаря | On weekdays: today's weather and calendar events |
| [evening_report.yaml](evening_report.yaml) | В 23:00: где горит свет и что открыто | At 23:00: which lights are on and what is open |
| [bedtime_story.yaml](bedtime_story.yaml) | Каждый вечер новая короткая сказка | A new short fairy tale every evening |
| [laundry_done.yaml](laundry_done.yaml) | Напоминание развесить бельё | A reminder to hang the laundry |
| [door_camera.yaml](door_camera.yaml) | Описание снимка с камеры, когда звонят в дверь | Describes the camera snapshot when the doorbell rings |
| [weather_walk.yaml](weather_walk.yaml) | Структурированный ответ: можно ли гулять | Structured answer: is it good for a walk |
| [image_postcard.yaml](image_postcard.yaml) | Утренняя открытка, нарисованная ГигаЧатом | A morning postcard drawn by GigaChat |
| [low_balance.yaml](low_balance.yaml) | Уведомление, когда заканчиваются токены | A notification when tokens run low |

Промпты написаны по-русски, перевод каждого есть в комментарии.
The prompts are in Russian, each one has an English translation in a comment.
